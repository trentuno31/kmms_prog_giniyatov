### Стурктура
Каждая папка формата *"year-mm-dd"* содержит код и файлы домашней работы соответствующей даты.

### Запуск
1. Клонируйте repo:
    ```
    git clone https://github.com/trentuno31/kmms_prog_giniyatov.git
    ```
2. Переместитесь в нужную папку и запустите файл **.bat**.
Пример:
    ```
    cd 2026_09_14_sort_2_vars/correct_variant
   ```
   ```
   . .\build_sort.bat
   ```
